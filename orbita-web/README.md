# Orbita — Portal Contábil

Site institucional do Orbita, o portal contábil inteligente.

## Stack

- React 18 + Vite
- React Router DOM
- CSS puro (sem frameworks)
- Deploy: Vercel

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Conecte o repositório na [Vercel](https://vercel.com) e o deploy será automático a cada push.
